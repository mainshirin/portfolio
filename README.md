# Portfolio Project

Dit project is mijn persoonlijke portfolio waarin ik mijn werk, leerproces en projecten presenteer. Het is gebouwd met **HTML**, **CSS** en **JavaScript** en wordt beheerd via **GitHub**.

## 📂 Structuur
- `index.html` – startpagina van het portfolio  
- `about.html` – informatie over mijzelf  
- `contact.html` – contactpagina  
- `css/` – map met alle stijlen (bijv. `main.css`)  
- `js/` – map met scripts (bijv. `script.js`)  
- `img/` – **vereiste map voor afbeeldingen** (logo’s, foto’s, achtergronden)  

> ⚠️ Alle afbeeldingen moeten in de `img`‑map staan. Voorbeeld:  
> ```html
> <img src="img/logo.png" alt="Logo">
> ```
